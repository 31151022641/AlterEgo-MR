# Free human face replacement candidates

The user rejected the generated portraits as insufficiently similar to the
supplied Memoji-style reference, and explicitly selected **free assets only**.
The user approved Rain and Snow as the new artist-created bases. This folder
preserves the original source archives and evaluation artwork. Runtime head
adaptations and packaged credits are documented in
[the character provenance](../../../ARTIST_PORTRAITS_LICENSES.md).

## Recommended artist-created bases

- **Rain**, Blender Studio, current character page v3 (download named Rain v3.3).
  [Official page](https://studio.blender.org/characters/rain/v3/).
  The official page lists a modeled character with layered facial controls and
  shape-key correctives, free under CC-BY. The downloaded archive contains
  `Rain v3.3/rain_v3.2.blend` and body, eyes, hair and clothing textures.
  Archive names are preserved here; the internal version differs from the ZIP name.
- **Snow**, Blender Studio, character page v4.
  [Official page](https://studio.blender.org/characters/snow/v4/).
  The page lists the same class of facial controls, shape-key correctives, and
  free CC-BY licensing. The downloaded `Snow_v4.2.zip` contains
  `Snow/snow_v4.2.blend`; its official preview is also saved here.

Both are modeled and rigged for Blender, and the current pages require Blender
4.1 or newer. Neither is a drop-in Android asset or a reconstruction of the
reference's original Memoji models. Both require head extraction/optimization,
material conversion, expression mapping and in-app visual/performance checks.
Physical headset appearance and performance must be checked separately from
source artwork and offline previews.
